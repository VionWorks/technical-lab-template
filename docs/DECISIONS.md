# Decisions

Record durable engineering decisions here so the repository explains not only what exists, but why.

Use this format:

## YYYY-MM-DD — Decision title

**Context**

What problem or trade-off forced a decision?

**Decision**

What was chosen?

**Evidence**

Which benchmark, test, experiment, or constraint supports it?

**Consequences**

What becomes easier, harder, faster, slower, or explicitly unsupported?
